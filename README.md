## [**TRY IT HERE!**](https://26097ek.github.io/Shooter)

## To Play:
Either:
+ Click the link above\

OR
+ Clone the repo:`git clone https://github.com/26097ek/Shooter.git`
+ Open the HTML file in your browser (`index.html`)

## Controls: 
+ WASD to move
+ Look around with mouse
+ Click to shoot
+ If you game over, refresh to try again.
